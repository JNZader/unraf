## Videos

Las grabaciones de las clases (`.mp4`) NO están en este repo (límite de 100MB por archivo de GitHub).
Se guardan por separado en Google Drive.

Si necesitás los videos, buscá el archivo `unraf-videos-clases-YYYYMMDD.zip` en tu Drive.
